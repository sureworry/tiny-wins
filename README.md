# Tiny Wins

Minimal daily wins journal — log what you conquered, see it accumulate over time.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173/preview.html](http://localhost:5173/preview.html) for the phone-frame preview.
